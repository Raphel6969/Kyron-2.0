# Product Personality — design/CONTEXT.md
_Generated by ui-context-inject. Guides all layout, color, and component hierarchy decisions._

1. **Who uses this tool and in what environment?**
   Enterprise SOC engineers, AI platform architects, and security compliance officers overseeing fleets of autonomous tool-using agents. They work in technical control-room environments where clarity, high data density, and instant response time are paramount.

2. **What does the primary screen need to feel like?**
   A deterministic mission control center. Clean page segregation:
   - **Command Center:** Real-time system status, 4 key health metrics, active session counter.
   - **Tool Registry:** High-density inventory, quarantine state, risk scores, and side-by-side semantic drift inspection.
   - **Authority & Leases:** Approval queue for call-scoped capability escalation with 1-click ruling.
   - **Live Trajectories & Egress:** Active agent sessions, source-attributed byte budgets, sharded exfiltration tracker.
   - **Cryptographic Evidence:** Immutable SHA-256 hash chains, Ed25519 signature validation, EU AI Act Article 50 export.
   - **Policy Studio:** TOML policy compiler, simulation mode, and atomic hot-reload.

3. **What is the emotional register of the product?**
   Serious, precise, unyielding, calm. This is an enterprise security firewall protecting critical infrastructure. No poppy neon pastels, no celebration confetti, no bubbly gradients, no AI sparkle clichés.

4. **What two reference sites are closest in domain tone?**
   - **Linear.app:** Precise 1px structural borders, dense data tables, keyboard shortcuts, muted steel accents.
   - **Cloudflare Zero Trust / Axiom.co:** Real-time telemetry density, high-contrast dark surfaces, authoritative status indicators.

5. **What is the single typography decision that matters most?**
   Monospace typography (`JetBrains Mono`, `Menlo`) for all technical identifiers, SHA-256 hashes, tool names, and signature blocks. Numerical metrics must stand out with high contrast against muted labels.

6. **What motion should NOT do on this product?**
   No bouncy spring easings, no hover zoom effects (`hover:scale-105`), no floating gradient orbs. Motion strictly serves orientation: smooth drawer slide-overs, tab cross-fades, and subtle border focus illumination.

7. **What does the hero/overview need to communicate in 3 seconds?**
   Total deterministic security posture: that 0 model tokens are spent on the security hot path, untrusted tools are automatically quarantined, and egress is strictly source-attributed.

8. **What is the primary data entity and how should it look?**
   The Tool Trust Card / Row: Server ID, tool identifier, deterministic state badge (`approved`, `quarantined`, `blocked`), risk percentage meter, and side-by-side semantic diff trigger.

9. **What should a first-time user see on an empty state?**
   A clean, professional state card: "All 35 connected enterprise MCP tools conform to active trust policies. Zero unapproved capability drifts." with a quick action to trigger a scan or reload policies.

10. **What would make a judge stop and say 'this looks real'?**
    Authentic enterprise tools (GitHub, AWS, Stripe, Slack, Postgres), side-by-side prompt injection diffs (`read ~/.ssh/id_rsa` vs safe canonical UTC time), live cumulative egress byte meters, and verifiable Ed25519 cryptographic signatures.
