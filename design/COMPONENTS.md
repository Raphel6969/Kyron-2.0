# COMPONENTS — Component Catalog & Living Inventory

> **Master Catalog:** Authorized primitives for Hack Engine frontends.

---

## Primitives Catalog
- `<Button>`: Variants `primary`, `secondary`, `destructive`. Handles `isLoading`, keyboard focus rings.
- `<Card>`: Variants `surface`, `raised`, `interactive`. 4px padding grid.
- `<Badge>`: High-contrast status indicators.
- `<Skeleton>`: Dimension-accurate shimmer placeholders. No spinning wheels.
- `<MetricCard>`: Live stat card with label, value, delta, and SQL aggregation proof.
